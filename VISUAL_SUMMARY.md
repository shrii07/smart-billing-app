## 🎨 Color Coding System

### What Each Color Means
```
BLUE   → Primary actions, bills, main features
GREEN  → Success, growth, positive metrics
PURPLE → Secondary actions, alternatives
ORANGE → Tax, warnings, special information
RED    → Delete, destructive actions, errors
GRAY   → Neutral, disabled, muted states
```

### Visual Hierarchy
```
Large/Bold/Colorful      → Important (actions, metrics)
Small/Gray/Muted        → Supporting (descriptions, helpers)
Colored/Gradient        → Interactive/Important
White/Light Gray        → Backgrounds
Dark Gray               → Text content
```

## 📊 Visual Hierarchy

### Size
```
Largest:     Page title (36px, black)
Large:       Section header (28px, bold)
Medium:      Body text (16px)
Small:       Labels (14px, semibold)
Smallest:    Helper text (12px)
```

### Color
```
Most Color:      Action buttons, badges
Colored Text:    Links, highlights
Gray Text:       Body content
Light Gray:      Muted information
Very Light:      Borders, backgrounds
```

### Weight
```
Heaviest:    Black (900) → Page titles
Heavy:       Bold (700) → Headings
Normal:      Regular (400) → Body
Semibold:    (600) → Labels
```
